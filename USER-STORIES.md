# USER-STORIES.md — Expload Marketing SaaS

Generated by discovery audit, 2026-09-04. Recovered from UI, API behavior, and schema — organized by persona (see `PRD.md` §2), then by module. Each story is tagged with its implementation status. Stories describing Stub/Missing behavior are written as if the feature worked as designed (that's the recoverable requirement); the gap itself is tracked in `KNOWN-ISSUES.md`, not hidden here.

Legend: ✅ Implemented · 🟡 Partial · 🔴 Stub/fake · ⚫ Missing

---

## Anonymous visitor

- As a visitor, I want to see the platform's value proposition and pricing on a public landing page, so that I can decide whether to sign up. ✅
- As a visitor, I want to try the product without creating an account, so that I can evaluate it before committing. ✅ (24-hour sandbox, capped at 20 actions)
- As a visitor, I want my sandbox trial to convert into a real account without losing my demo progress, so that trying the product isn't wasted effort. 🟡 (`sandbox/convert` exists; not independently verified this pass whether demo data actually carries over)
- As a visitor, I want to browse the company blog and read published articles, so that I can evaluate the platform's expertise. ✅
- As a visitor, I want to use a pricing calculator to estimate my monthly cost before signing up. ✅

## Tenant Owner (self-signup)

- As a new owner, I want to sign up with just my name, email, password, and company name, so that I can start using the platform immediately. ✅
- As an owner, I want a new tenant to come with sample data (leads, a funnel, a welcome journey, fraud rules) so that I can explore features without starting from a blank slate. ✅ (the "1-click auto-setup" on signup)
- As an owner, I want to invite teammates by email with a specific role, so that my team can collaborate in the same tenant. ✅ (fixed this session — previously the invite link led nowhere for new emails)
- As an owner, I want to define a custom role with a specific set of permissions, so that I can grant exactly the access a teammate needs. 🟡 **UI exists and appears to work, but has zero actual effect on access control** — see `KNOWN-ISSUES.md` / `BUSINESS-RULES.md` §2.
- As an owner, I want to see an audit log of who did what in my tenant, so that I have accountability. ✅
- As an owner, I want to configure which payment gateways my tenant accepts, so that my customers can pay how they prefer. 🔴 Only crypto (NOWPayments/manual wallets) actually processes a payment; 11 "configured" card gateways are non-functional.

## Tenant team member (any role)

- As a team member, I want to discover new business leads by industry/location, so that I can build a prospect list. ✅ (real search API + Google Maps scraping, with a documented mock fallback)
- As a team member, I want each lead automatically enriched with firmographic/contact data and scored, so that I know who to prioritize. ✅
- As a team member, I want to manage deals through a CRM pipeline, so that I can track sales progress. ✅
- As a team member, I want to send an email campaign to a segment of leads, so that I can nurture prospects at scale. ✅ (queuing has a robustness gap if Redis is misconfigured — see `KNOWN-ISSUES.md`)
- As a team member, I want to message customers on WhatsApp from inside the platform, so that I don't need a separate tool. 🔴 UI/data model exist; no message is ever actually sent to WhatsApp.
- As a team member, I want to send SMS notifications to customers. 🔴 Same — logged, never sent.
- As a team member, I want an embeddable chatbot widget for my website that captures leads automatically. ✅
- As a team member, I want to monitor my Google/Yelp/Trustpilot reviews and respond from one place. ✅
- As a team member, I want to plan and schedule content across a calendar. ✅
- As a team member, I want SEO crawl results (issues, keyword tracking, backlink authority) for my site. 🔴 Crawl results are always randomly generated, never a real crawl.
- As a team member, I want to discover new backlink opportunities. 🔴 Always fabricated data.
- As a team member, I want to run and track A/B tests on landing pages/campaigns. ✅ (CRUD-level; no independent verification this pass of a real statistical significance calculation)
- As a team member, I want to manage ad campaigns across platforms from one dashboard. ✅ (CRUD-level)
- As a team member, I want to manage social accounts and schedule posts. ✅ (CRUD-level)
- As a team member, I want to monitor brand mentions across the web/social. ✅ (CRUD-level)
- As a team member, I want a competitor deep-analysis report. 🔴 Always fabricated data (`Math.random()`-based).
- As a team member, I want AI-generated content ideas and marketing strategy advice. ✅ (via the real LLM aggregator, when configured)
- As a team member, I want to build multi-step automated workflows (triggers → actions → conditions → waits). ✅ (CRUD/data-model level; execution engine not independently re-verified this pass)
- As a team member, I want an autonomous agent that can execute a multi-step marketing goal on its own via a graph-based plan. ✅ (data model + orchestrator exist; real-world reliability not independently benchmarked this pass)
- As a team member, I want to build a real conversion funnel and see drop-off between stages, with real visitor counts. ✅ (built this session — funnel/journey are now backed by real create/view/delete, previously static demo data)
- As a team member, I want to design an automated customer journey (trigger → wait → action sequence) and see who's enrolled/converted. ✅ (built this session)
- As a team member, I want to see which acquisition channels are driving results and catch click fraud. ✅
- As a team member, I want to register a webhook endpoint so my own systems get notified of platform events in real time. ✅ (built this session)
- As a team member, I want to submit a campaign/content/ad/budget item for a manager's approval before it goes live. 🟡 (built this session — the approval queue itself works for manual submissions; no other feature in the app yet auto-creates an approval request, so this only works if used deliberately, not as an automatic gate on publishing)

## SuperAdmin (platform operator)

- As a superadmin, I want to see every tenant, its plan, and its usage, so that I can operate the platform. ✅ (also currently over-exposed to any signed-up user via `GET /api/tenants` — see `KNOWN-ISSUES.md` #4)
- As a superadmin, I want to enable/disable any tenant. ✅
- As a superadmin, I want to promote or demote another user to superadmin. ✅
- As a superadmin, I want to see platform-wide MRR/ARR and revenue. ✅ (dashboard-level; accuracy depends on the same stub payment gateways noted above)
- As a superadmin, I want to configure which LLM providers are active and see usage/cost across the whole platform. ✅
- As a superadmin, I want to reset a misconfigured LLM provider's stored key/config back to defaults. ✅ (built this session)
- As a superadmin, I want visibility into the background job queue's health. ✅ (built this session — previously no UI at all, and the endpoint itself crashed if Redis was down; both fixed)
- As a superadmin, I want to test semantic search over indexed content. ✅ (built this session)
- As a superadmin, I want to generate and archive point-in-time financial report snapshots for compliance/audit, separate from the live dashboard numbers. ✅ (built this session)
- As a superadmin, I want to configure real payment gateway credentials for the platform. 🟡 The form/storage works; most gateways don't actually process a payment once configured (see above).
- As a superadmin, I want a full platform audit log. ✅

## Internal Employee ("Operator")

- As an internal employee, I want to be added to a department with a manager, so that the org structure reflects reality. ✅
- As an internal employee, I want to see and edit my own profile/role details, subject to what my platform role allows. ✅ (edit/terminate built this session; previously create-only)
- As an admin-level internal employee, I want to add new staff, but not be able to grant myself or others super_admin — only a true superadmin should be able to do that. ✅ (fixed this session — this was previously a real privilege-escalation gap)
- As an internal employee assigned to distributor management, I want to see the distributors/territories I'm responsible for. ✅

## Distributor

- As a distributor, I want to purchase license packages wholesale and see them added to my pool. ✅ (license-key generation and expiry work; note the batch payment-recorded amount doesn't scale with quantity — likely a real calculation bug, see `BUSINESS-RULES.md` §5)
- As a distributor, I want to allocate individual licenses from my pool to my own customers. ✅
- As a distributor, I want an exclusive territory with a minimum sales commitment. ✅ (data model + CRUD; the commitment isn't tied to any automatic enforcement/alert this pass found)
- As a distributor, I want to request a payout of my share of sales. 🟡 The request/approval workflow works, but **no formula computes what my actual share should be** — the amounts are trusted as submitted, not calculated from my contract's discount/commission terms.
- As a distributor, I want to escalate a support ticket through tier 1/2/3. ✅

## Support-plan customer

- As a customer, I want to subscribe to a support plan (Basic/Premium/Enterprise) with a guaranteed response time. 🟡 Subscription and the deadline *timestamp* work correctly; **nothing in the system actually checks whether that deadline was met** — there's no breach alert or escalation, so the "guarantee" isn't operationally enforced.
- As a customer, I want to submit and track support tickets with priority levels. ✅
- As a customer, I want to rate my support experience after resolution. ✅

## Virtual-assistant client

- As a client, I want to browse available virtual assistants by skill and hire one hourly/fixed/retainer. ✅
- As a client, I want to see logged hours and productivity data for my assigned assistant. ✅
- As a client, I want automatic billing based on logged, approved hours. ✅ (feeds into payroll — see `BUSINESS-RULES.md` §4)

## Marketplace / API consumer

- As a developer, I want to purchase API access as a product and receive an API key. ✅
- As a developer, I want to track my own API usage against my plan limits. ✅
- As a developer, I want confidence that only I can modify my own marketplace listing. 🔴 Currently, any signed-up user of any tenant can modify/delete any marketplace product listing — see `KNOWN-ISSUES.md` #5.
